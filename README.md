# Graph Plan

## Summary
I want to make a canvas the user can draw nodes for a graph on, and have a
variety of algorithms and visualizations animated for the user.

For example, some searches like BFS, DFS, and A*, as well as some non-search
algorithms like finding the convex hull, and some clustering algorithms maybe.

## Tech Stack
- Basic HTML, CSS, JS, Python
- Drawing and updating elements is possible in pure JS--a good exercise to
learn the tools:
    * https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Client-side_APIs/Drawing_graphics

## Learning Goals
* HTML, CSS: basic front-end proficiency
* JS: interactive elements

## Notes
Python will be used for the backend for pedagogy. I sometimes write
instructional materials for students, and being able to see the algorithms
running in a more familiar language could be helpful. Plus writing some backend
logic interop would be a good learning experience for me.
